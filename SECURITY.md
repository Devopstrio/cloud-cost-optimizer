# Security Policy

## Reporting Security Vulnerabilities

We take security issues seriously. If you discover a vulnerability in the Cloud Cost Optimizer engine, please report it via security@devopstrio.co.uk.

Do NOT report security vulnerabilities through public GitHub issues.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
